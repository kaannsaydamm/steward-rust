# Governance

Steward is currently maintained as a single-maintainer open-source project.

## Maintainer

- **Kaan Kadir Aluçlu** — creator and primary maintainer

The maintainer is responsible for project direction, security response, release decisions, repository administration, issue and pull-request triage, and enforcement of the Code of Conduct.

## Decision making

Project decisions are made in public issues and pull requests whenever security or privacy does not require a private discussion. Decisions prioritize, in order:

1. user and system security;
2. predictable local-first behavior and data portability;
3. backward compatibility and migration safety;
4. maintainability and testability;
5. ecosystem interoperability.

For substantial or breaking changes, contributors should open an issue before implementation. The maintainer may request a design note, migration plan, security analysis, or additional tests before accepting a change.

## Contributions and reviews

The maintainer may merge, request changes, defer, or decline contributions based on project scope, quality, security, compatibility, and maintenance cost. A contribution is not guaranteed to be accepted solely because implementation work has begun.

## Releases

Only the maintainer may publish official Steward releases, packages, signed artifacts, or security advisories unless that authority is explicitly delegated in this document.

## Future maintainers

Additional maintainers may be invited after a sustained record of constructive participation, reliable reviews, security-conscious engineering, and alignment with the project's goals. Any change to maintainer status will be recorded in this document through a public pull request.
